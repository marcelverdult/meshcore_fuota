Alpha-Test: Was du tun musst

Lies nur diese Seite. Alles andere ist für Neugierige. Repeater holen sich neue Firmware per Funk, ohne dass jemand aufs Dach muss. Du spielst eine Datei auf deinen Repeater, richtest ihn ein und wartest. Den Rest macht der Repeater allein.

Alpha test: what you need to do

Read only this page. Everything else is for the curious. Repeaters fetch new firmware over the air, and nobody has to climb a roof. You put one file on your repeater, set it up and wait. The repeater does the rest on its own.

1. Allein passiert nichts

1. Alone, nothing happens

Ein einzelner Repeater bekommt nie ein Update.

Ein Update wandert von Repeater zu Repeater. Steht dein Repeater allein, hört er niemanden, der es ihm anbietet. Dann wartet er ohne Ende.

In derselben MeshCore-Region laufen immer mindestens 2 Test-Repeater. Genau einer davon ist der Seed. Alle anderen bekommen das Basis-Paket. Alle stehen in Funkreichweite zueinander.

Du hast mehrere Geräte? Dann geht es allein: Ein Gerät wird Seed, die anderen werden Basis.

Du hast nur ein Gerät? Such dir Mit-Tester aus deiner Region, am besten im Telegram-Thread (alternativ im Discord). Sprecht ab, wer Seed ist, dann fangt ihr an. Eine Freigabe dafür braucht ihr nicht.

A single repeater never gets an update.

An update travels from repeater to repeater. If your repeater stands alone, it hears nobody who offers it. Then it waits forever.

At least 2 test repeaters always run in the same MeshCore region. Exactly one of them is the seed. All others get the base package. All of them are within radio range of each other.

Do you have several devices? Then you can do it alone: one device becomes the seed, the others become base.

Do you have only one device? Look for fellow testers in your region, best in the Telegram thread (or in Discord). Agree who is the seed, then start. You need no approval for that.

2. Welche Datei ist für dich?

2. Which file is yours?

Basis-Paket: für dich

Für fast alle Geräte. Dein Repeater holt sich damit das Update.

Der Dateiname enthält -base-:
meshcore-fuota-1.17.1-fuota1-base-<Board>-<SoftDevice>.uf2

Du findest es im Release v1.17.1-fuota1.

Seed-Paket: nur für einen

Nur für das eine Gerät, das ihr als Seed abgesprochen habt. Je Gruppe genau eins.

Der Dateiname enthält -seed-:
meshcore-fuota-1.18.0-b5-seed-<Board>-<SoftDevice>.uf2

Du findest es im Vorab-Release v1.18.0-fuota5, also nicht im Release der Basis-Pakete.

Base package: for you

For almost every device. Your repeater fetches the update with it.

The file name contains -base-:
meshcore-fuota-1.17.1-fuota1-base-<board>-<SoftDevice>.uf2

You find it in the release v1.17.1-fuota1.

Seed package: for one only

Only for the one device that you agreed on as the seed. Exactly one per group.

The file name contains -seed-:
meshcore-fuota-1.18.0-b5-seed-<board>-<SoftDevice>.uf2

You find it in the pre-release v1.18.0-fuota5, so not in the release of the base packages.

Das Seed-Paket trägt die Firmware 1.18.0 und das Update von 1.17.1 auf 1.18.0. Der Seed bietet es seinen Nachbarn an. Die Basis-Geräte laufen mit 1.17.1-fuota1 und holen es von ihm. Wähle bei beiden das Board und das SoftDevice deines Geräts. Die Namen aller Boards stehen in der Tabelle der Alpha-Seite.

Wenn alle ihr eigenes Seed-Paket aufspielen, weiß niemand mehr, woher das Update kommt. Dann können wir den Test nicht auswerten.

The seed package carries the firmware 1.18.0 and the update from 1.17.1 to 1.18.0. The seed offers it to its neighbours. The base devices run 1.17.1-fuota1 and fetch it from the seed. For both, choose the board and the SoftDevice of your device. The names of all boards are in the table on the alpha page.

If everyone installs their own seed package, nobody knows any more where the update came from. Then we cannot evaluate the test.

3. Die alte Version muss weg

3. The old version has to go

Warst du beim ersten Test dabei?

Dann läuft auf deinen Repeatern vielleicht noch die alte Test-Version (1.17.1-b2 oder 1.18.0-b3). Sie passt nicht mehr. Spiel auf jeden Repeater das neue Paket, auch auf den zweiten und dritten.

So prüfst du es: Tippe in der USB-Konsole ver. Ein Basis-Gerät antwortet v1.17.1-fuota1 (Build: 14 Aug 2026). Der Seed zeigt v1.18.0-fuota5. Steht da etwas anderes, spiel das Paket neu auf.

Did you take part in the first test?

Then your repeaters may still run the old test version (1.17.1-b2 or 1.18.0-b3). It no longer fits. Put the new package on every repeater, also the second and the third.

How to check: type ver in the USB console. A base device answers v1.17.1-fuota1 (Build: 14 Aug 2026). The seed shows v1.18.0-fuota5. If it says anything else, install the package again.

4. Die Schritte

4. The steps

  1. Seed festlegen. Mindestens 2 Test-Repeater in deiner Region, genau einer davon Seed.
  2. Board finden. Such in der Tabelle die Zeile mit deinem Gerät, zum Beispiel RAK4631.
  3. Datei laden. Basis-Geräte nehmen die Datei mit -base- im Namen, der Seed die mit -seed-.
  4. Aufspielen. USB anstecken, 2-mal schnell Reset drücken und die Datei auf das neue Laufwerk ziehen.
  5. Einrichten. Tippe diese Befehle in der USB-Konsole. Ersetze die Teile in spitzen Klammern:
    • password <dein Passwort> (höchstens 15 Zeichen, nicht password)
    • set name FUOTA <Spitzname> 1.17.1-fuota1 (beim Seed: 1.18.0-fuota5)
    • region default hansemesh (den Namen der Region deines Netzes, in allen Geräten gleich)
    • set lat <Breite> und set lon <Länge> (grob reicht)
    • set advert.interval 240
  6. Prüfen. ver zeigt die Version aus Abschnitt 3. Ein Gerät, das noch nichts angeboten bekommen hat, meldet mit fuota info den Satz no update. Beim Seed beginnt die Meldung mit passing on update 950257b4.
  7. Warten. Tu nichts weiter. Das Holen dauert viele Stunden. Danach wartet der Repeater ab Werk noch 7 Tage, bevor er das Update anwendet.
  1. Pick the seed. At least 2 test repeaters in your region, exactly one of them the seed.
  2. Find your board. Look up the row with your device in the table, for example RAK4631.
  3. Download the file. Base devices take the file with -base- in its name, the seed the one with -seed-.
  4. Install it. Plug in USB, press Reset twice quickly and drag the file onto the new drive.
  5. Set up. Type these commands in the USB console. Replace the parts in angle brackets:
    • password <your password> (15 characters at most, not password)
    • set name FUOTA <nickname> 1.17.1-fuota1 (on the seed: 1.18.0-fuota5)
    • region default hansemesh (the name of your network's region, the same on all devices)
    • set lat <latitude> and set lon <longitude> (rough is enough)
    • set advert.interval 240
  6. Check. ver shows the version from section 3. A device that has been offered nothing yet answers fuota info with no update. On the seed the reply starts with passing on update 950257b4.
  7. Wait. Do nothing else. Fetching takes many hours. After that the repeater waits 7 more days by default before it applies the update.

5. Warum es dauert, und warum manchmal gar nichts kommt

5. Why it takes long, and why sometimes nothing comes

Der Seed ruft nur selten. Direkte Nachbarn ruft er anfangs oft, dann immer seltener, am Ende alle 2 Tage. Weiter entfernte Repeater erreicht er nur mit einer Flut. Die schickt er in der ersten Woche höchstens einmal am Tag, danach einmal pro Woche. Das ist Absicht: So bleibt das Mesh frei für normale Nachrichten.

Wer den Ruf nicht hört, fragt nicht. Dein Repeater meldet sich erst, wenn er einen Ruf gehört hat. Geht der Ruf verloren, wartet er bis zum nächsten.

The seed calls rarely. It calls direct neighbours often at first, then less and less, in the end every 2 days. It reaches repeaters farther away only with a flood. It sends one at most once a day in the first week and once a week after that. That is on purpose: it keeps the mesh free for normal messages.

Whoever does not hear the call does not ask. Your repeater speaks up only after it has heard a call. If the call is lost, it waits for the next one.

Warum ein Ruf verloren geht
Viel Verkehr im Mesh: Zwei Pakete gleichzeitig stören sich.
Falsche oder keine Region: Der Ruf kommt in deiner Region nie an.
Zu weit weg oder schlechter Empfang.
Why a call gets lost
Much traffic in the mesh: two packets at the same time disturb each other.
Wrong or no region: the call never arrives in your region.
Too far away or poor reception.

Hat er den Ruf gehört, fragt er zurück. Die Frage geht auf dem Weg zurück, den der Ruf genommen hat. Bleibt sie 2-mal ohne Antwort, schickt er sie einmal per Flut, also an alle. Das klappt, dauert aber: Eine solche Flut-Anfrage schickt ein Repeater höchstens einmal pro Stunde.

Hört er mehrere Angebote, fragt er auch mehrere Seeds. Er merkt sich bis zu 4 Anbieter und wechselt, wenn einer nicht antwortet.

Es sind nur wenige Nachrichten. Geht eine davon verloren, verschiebt sich alles bis zum nächsten Versuch. Darum kann es Tage dauern. Das ist im Test normal.

Viele Hops, viel Verlust. Im Test gibt es nur wenige FUOTA-Repeater. Darum liegen zwischen Seed und dir oft viele Hops, also viele Repeater dazwischen. Jeder Hop kann ein Paket verlieren. Je mehr Hops, desto größer das Risiko.

Später wird es schneller. Das Basis-Paket 1.17.1-fuota1 gibt selbst nichts weiter. Es holt das Update nur. Erst mit 1.18 gibt jeder Repeater das Update an seine Nachbarn weiter. Haben viele Repeater FUOTA, muss nicht mehr alles vom Seed kommen.

If it heard the call, it asks back. The question goes back along the way the call took. If it stays unanswered twice, it sends the question once as a flood, so to everybody. That works, but it takes time: a repeater sends such a flood request at most once an hour.

If it hears several offers, it asks several seeds. It remembers up to 4 providers and switches when one does not answer.

It is only a few messages. If one of them is lost, everything shifts to the next try. That is why it can take days. In the test that is normal.

Many hops, much loss. In the test there are only a few FUOTA repeaters. So there are often many hops between the seed and you, that is many repeaters in between. Each hop can lose a packet. The more hops, the greater the risk.

Later it gets faster. The base package 1.17.1-fuota1 passes nothing on itself. It only fetches the update. Only with 1.18 does every repeater pass the update on to its neighbours. If many repeaters run FUOTA, not everything has to come from the seed.

6. Der Analyzer hört nur zu

6. The analyzer only listens

Stell dir vor, du stehst vor einem Haus und hörst durchs Fenster, wie drinnen jemand redet. Du verstehst nur Bruchstücke und rätst den Rest. So ähnlich arbeitet der Analyzer. Er fragt deinen Repeater nicht. Er kennt nur die Funkpakete, die ein Observer in der Nähe zufällig mitbekommt.

Im Tab Rollout stehen zwei Quellen nebeneinander. Die eine sind Statusmeldungen, die ein Repeater selbst sendet. Das tut er nur mit Standard-Region und höchstens 8-mal in 24 Stunden. Die andere sind Angebote, die ein Observer gehört hat. Ein gehörtes Angebot nennt, wie viele Seiten der Absender hat. Dieser Stand kann schon veraltet sein. Fehlt ein Wert, zeigt der Analyzer einen Strich. Alle Zahlen sind Mindestwerte.

Imagine you stand in front of a house and hear someone talk inside through the window. You catch only fragments and guess the rest. The analyzer works a bit like that. It does not ask your repeater. It knows only the radio packets that an observer nearby happens to catch.

The Rollout tab puts two sources side by side. One is status messages that a repeater sends itself. It does so only with a default region and at most 8 times in 24 hours. The other is offers that an observer has heard. A heard offer says how many pages its sender holds. That state may already be out of date. If a value is missing, the analyzer shows a dash. All numbers are lower bounds.
