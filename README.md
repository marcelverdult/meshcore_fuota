# MeshCore FUOTA

**Deutsch:** Firmware-Updates über LoRa für MeshCore-Repeater. Dieses Repository enthält vorerst die Beschreibung
des Entwurfs zur Prüfung und die Anleitung für den Alpha-Test, auf Deutsch und Englisch:
**https://marcelverdult.github.io/meshcore_fuota/**

Stand: Proof of Concept, Basis MeshCore 1.18.0, am Brett gemessen mit FakeTecs (nRF52840, S140 6.1.1), einem
SenseCAP P1 (S140 7.3.0) und einem RAK4631. Seit dem 11. November 2026 läuft ein Alpha-Test mit 1.17.1-b2 und
1.18.0-b3, die Pakete liegen als Releases in diesem Repository. Eine allgemeine Freigabe gibt es nicht. Nichts davon ist
in MeshCore eingereicht.
Der Quellcode folgt später. Wir suchen Denkfehler: Rückmeldungen bitte als Issue.

**English:** Firmware updates over LoRa for MeshCore repeaters. For now this repository holds the description of the
design for review and the guide for the alpha test, in German and English:
**https://marcelverdult.github.io/meshcore_fuota/**

Status: proof of concept based on MeshCore 1.18.0, measured on the bench with FakeTecs (nRF52840, S140 6.1.1), one
SenseCAP P1 (S140 7.3.0) and one RAK4631. An alpha test with 1.17.1-b2 and 1.18.0-b3 has been running since
11 November 2026, and the packages are releases in this repository. There is no general release. Nothing of it has been
submitted to MeshCore. The source code follows later. We are looking for flaws in the reasoning: please send feedback as an issue.
