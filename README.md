# MeshCore FUOTA

**Deutsch:** Firmware-Updates über LoRa für MeshCore-Repeater. Dieses Repository enthält vorerst nur die Beschreibung
des Entwurfs zur Prüfung, auf Deutsch und Englisch:
**https://marcelverdult.github.io/meshcore_fuota/**

Stand: Proof of Concept auf drei FakeTecs (nRF52840), Basis MeshCore 1.18.0. Nichts davon ist in MeshCore eingereicht.
Der Quellcode folgt später. Wir suchen Denkfehler: Rückmeldungen bitte als Issue.

**English:** Firmware updates over LoRa for MeshCore repeaters. For now this repository holds only the description of
the design for review, in German and English:
**https://marcelverdult.github.io/meshcore_fuota/**

Status: proof of concept on three FakeTecs (nRF52840), based on MeshCore 1.18.0. Nothing of it has been submitted to
MeshCore. The source code follows later. We are looking for flaws in the reasoning: please send feedback as an issue.
